# Pawn&Run — UI 아트 제작 기획서 (Codex 작업용)

이 문서 하나로 Pawn&Run의 모바일 UI 아트를 전부 생성할 수 있도록 정리했습니다. 지금 Unity 프로젝트는 기능적으로는 완성돼 있고(화면 전환, 게임 로직, 포획 애니메이션/효과음 전부 동작), **아트만 임시 플레이스홀더(단색 도형, 절차적으로 생성한 스프라이트)** 상태입니다. 이 기획서를 기준으로 실제 완성도 있는 아트를 만들어서, 아래 "에셋 마스터 리스트"의 **동일한 파일명/경로로 덮어쓰면** 코드 수정 없이 바로 적용됩니다.

## 1. 프로젝트 개요

- **게임명**: PAWN & RUN | 폰 & 런
- **장르**: 모바일 세로형 캐주얼 서바이벌. 체스 폰 하나가 위에서 밀려 내려오는 적 폰들을 피하거나 대각선으로 포획하며 최대한 오래 버티는 게임
- **핵심 톤**: 체스의 정제된 느낌 + 러너 게임의 속도감. 유치한 하이퍼캐주얼이 아니라, **세련되고 깔끔한 모던함**
- **플랫폼**: 모바일 (세로 화면 고정)
- **참고 자료**: `design/ui-mockups/*.pdf` (초기 와이어프레임/목업, 레이아웃 구조 참고용), `web-prototype/index.html` (게임 규칙·룰 원본)

## 2. 비주얼 아이덴티티

### 무드
정밀함(체스) + 순간적인 스피드(런)가 동시에 느껴지는 균형. 3D 렌더, 과한 그라데이션, 만화적 효과음 이펙트, 스톡 게임 클리셰(주사위·게임패드 아이콘)는 피할 것.

### 타이포그래피
- 폰트: **Noto Sans KR** (Regular/Bold, OFL 라이선스로 이미 프로젝트에 포함됨 — 새 폰트 제안 불필요, 이 폰트에 맞춰 레이아웃 잡을 것)
- 영문 로고("PAWN & RUN")만 예외적으로 별도 디스플레이 서체 사용 가능 (아래 로고 항목 참고)

### 로고
- 메인 워드마크: **"PAWN & RUN"** (영문) + **"폰 & 런"** (한글 서브타이틀, 같은 락업 안에 함께)
- 스타일: 세련되고 깔끔한 모던 타이포그래피. 지오메트릭하고 볼드한 산세리프 또는 세리프-산세리프 하이브리드
- 체스 모티프는 직접적인 일러스트보다 **타이포그래피에 은근히 녹아든 형태**로 (예: "PAWN"의 O/A를 폰 실루엣과 결합, "&"를 폰 형태로 재해석, RUN 끝부분에 스피드 느낌의 사선 컷)
- 컬러: 딥브라운(`#3A2F22`)/크림골드(`#E9DE9A`) 2톤 조합 + 앰버(`#B5772E`) 포인트 소량
- **버전 4종 필요**: 컬러 가로형 풀 로고, 컬러 정사각형 심볼(앱 아이콘용), 다크 모노톤(딥브라운/블랙 단색), 라이트 모노톤(크림/골드 단색)
- 작게 축소해도(앱 아이콘 크기) 형태가 뭉개지지 않을 것

## 3. 기술 스펙

- **기준 해상도**: 1080×1920 (9:16 세로), Canvas Scaler `Scale With Screen Size` 기준
- **세이프 에어리어**: 상하 약 80px 여백 두고 핵심 UI 배치 (노치/제스처 바 대응)
- **포맷**: PNG, 배경 투명, sRGB. 아이콘류는 정사각형 원본(예: 256×256) 권장, Unity에서 Sprite (2D and UI)로 임포트됨
- **타일 배경**(체크보드, 잔디)은 Repeat 가능한 시임리스 텍스처로 제작
- **버튼류**는 9-slice로 확장 가능한 형태(모서리 라운드 처리 별도 여백 확보) 권장

## 4. 화면별 상세 스펙

### 4-1. 시작화면 (Splash) — `SplashScene.unity`
- 배경: 체크보드 타일 (전체화면)
- 중앙: 로고 카드(나무 액자 프레임 + 크림/골드 배경) 안에 "PAWN & RUN / 폰 & 런" 로고
- 하단 문구: "화면을 터치하여 시작!"
- 인터랙션: 화면 전체 터치 → 메인화면 이동

### 4-2. 메인화면 — `MainScene.unity`
- 배경: 체크보드 타일
- 우상단: 원형 톱니 아이콘 버튼(청록 배경) → 환경설정 모달
- 중앙: 로고 카드
- 버튼 2개(세로 스택): **게임 시작**(초록 채움), **랭킹**(연노랑 채움), 검정 얇은 테두리 + 둥근 모서리

### 4-3. 환경설정 모달
- 오버레이 (배경 살짝 어둡게)
- 우상단 빨간 원형 X 닫기 버튼(글로시한 완성 버튼 그래픽)
- 주황 패널 안에 **배경음**/**효과음** 라벨 + 슬라이더 2개

### 4-4. 랭킹화면 — `RankingScene.unity`
- 배경: 체크보드 타일, 우상단 X 닫기
- 상단: 로고 카드 + "랭킹" 서브타이틀
- 리스트(스크롤): 각 행 = 순번 박스 + 아바타 아이콘(기본 플레이스홀더, 원형) + 닉네임/점수 박스

### 4-5. 게임화면 — `GameScene.unity`
- 배경: 잔디 텍스처(타일링)
- 상단 스탯 바(갈색 패널): HIGH SCORE / SCORE 라벨+값, 시계 아이콘 + 타이머, 빨간 X(종료)/청록 톱니(설정) 원형 버튼
- 보드: 5×7 오렌지/탠 체커, 갈색 프레임
- 하단: 이동 버튼 3개(↖ ↑ ↗), 흰 배경 + 검정 화살표 아이콘, 텍스트 라벨 없음
- 버튼 상태 3종 필요: **normal**(기본), **ready**(강조, 지금 누를 수 있는 액션), **disabled**(흐림)

### 4-6. 게임 내 환경설정 모달
- 게임화면 위 오버레이, 뒤 배경(보드/스탯바)이 회색조로 딤 처리
- 구성은 4-3과 동일

## 6. 참고: 이미 구현된 인터랙션(아트 제작 시 참고용)

- 포획 성공 시: 대상 칸이 확대되며 페이드아웃 + "+10" 점수 팝업이 위로 떠오름
- 불가능한 이동 시도 시: 보드 전체가 흔들림(shake)
- 버튼 상태: 지금 누를 수 있는 액션은 `ready`(강조색), 아니면 `disabled`(흐림) — 위 3-state 버튼 에셋이 이 상태를 그대로 반영해야 함
- 최고 점수 갱신 시: 점수판에 글로우 펄스 효과 (색상만 처리, 별도 에셋 불필요)

## 7. 산출물 제출 형식

- 전부 PNG (투명 배경), 위 표의 정확한 파일명/경로 유지
- 로고 4종은 SVG도 함께 제출 권장 (추후 다른 사이즈로 재활용)
- 라이트/다크 테마 전환은 현재 코드가 색상 값으로 처리하므로, 아이콘류는 **단색 실루엣(currentColor 스타일)**로 제작하면 재사용성이 가장 좋음 — 배경/텍스처류만 라이트·다크 버전 각각 제작
