# Pawn&Run | 폰앤런

폰이 앞에서 밀려오는 적을 포획하며 최대한 오래 버티는 미니 로그라이크. 지금부터 Unity(6.3 LTS / 6000.3.19f1, 2D, 내장 렌더 파이프라인)로 정식 개발합니다.

웹 프로토타입(HTML/CSS/JS 단일 파일)은 `web-prototype/`에 참고용으로 남겨뒀습니다. 게임 규칙과 밸런스를 그대로 옮겨오는 기준점으로 쓰세요.

## 시작하기 (Unity Hub)

1. Unity Hub에서 **Add project from disk** → 이 저장소 루트 폴더 선택
2. 설치된 에디터 버전이 `ProjectSettings/ProjectVersion.txt`에 적힌 `6000.3.19f1`과 다르면 Hub가 업그레이드 여부를 물어봅니다 → 예로 진행 (부 버전 차이는 무해합니다)
3. 처음 열 때 `ProjectSettings/`의 나머지 설정 파일과 `Assets/Scenes`의 씬은 비어 있으므로, `Assets/Scenes`에 새 씬을 만들어 저장해주세요 (예: `MainScene.unity`)
4. Git LFS를 쓰려면 (권장 — 스프라이트/오디오 등 바이너리 에셋 추가 전) 로컬에서 한 번만: `git lfs install`

## 폴더 구조

```
Assets/
  Scripts/      게임 로직, C# 스크립트
  Scenes/       씬 파일
  Prefabs/      프리팹
  Art/Sprites/  스프라이트/이미지
  Audio/        효과음/BGM
  Fonts/        폰트
Packages/       manifest.json (패키지 의존성)
ProjectSettings/
web-prototype/  기존 HTML 프로토타입 (참고용, 플레이 가능)
```

## 게임 규칙 (웹 프로토타입 기준)

- 보드: 5열 × 7행. 플레이어 폰은 맨 아래 행에 고정, 적 폰이 위에서 아래로 한 칸씩 밀려 내려옴
- 매 턴 행동: **전진**(정면이 비어 있으면 이동) / **좌·우 대각선 포획**(대각선에 적이 있으면 잡고 이동, +10점)
- 정면이 막히고 양쪽 대각선도 비어 있으면 게임 오버
- 제한시간 3분 — 점수 상한용이며, 시간 종료도 게임 오버로 처리
- 시작 후 4턴은 완전히 막히지 않도록 보호 (`ensureSafeFront`)
- 한 행에 배치되는 적은 1~3개 (5칸 중), 점수 120점(레벨 6)에서 난이도 상한
- 최고 점수는 로컬에 저장

세부 수치·엣지케이스는 `web-prototype/index.html`의 스크립트 주석을 참고하세요.

## 참고: 밸런스 관련 알려진 특성

보드 전체(전방부터 맨 위 행까지)가 항상 화면에 보이기 때문에, 몇 수 앞을 내다보고 플레이하면 사실상 거의 죽지 않는다는 점이 시뮬레이션으로 확인되었습니다 (자세한 내용은 이전 대화 기록 참고). Unity로 재구현할 때 이 부분을 그대로 가져갈지, 난이도 상한을 없애거나 가시 범위를 줄이는 방향으로 조정할지 결정이 필요합니다.
