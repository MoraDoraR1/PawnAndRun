# RunPawn 기획서

## 1. 게임 개요

| 항목 | 내용 |
|---|---|
| 가제 | RunPawn |
| 장르 | 턴제 체스 기물 서바이벌 (1레인 러너 + 체스 폰 규칙) |
| 플랫폼 | 미정 (웹/모바일 대응 가능한 단순 그리드 게임) |
| 한 줄 소개 | 체스의 "폰"이 되어, 위에서 끊임없이 내려오는 적 폰들을 피하거나 대각선으로 잡아내며 최대한 오래 버티는 하이스코어 게임 |
| 보드 크기 | 7행 × 5열 |

플레이어는 체스의 폰 기물 하나를 조작한다. 폰은 항상 **1행에 위치**하며, 적 폰들은 **7행에서 무작위로 등장해 매 입력마다 1행씩 하강**한다. 플레이어는 실제 체스 폰의 이동 규칙(전진 1칸 / 대각선 포획)을 그대로 사용해 내려오는 적을 피하거나 제거하며 생존한다.

---

## 2. 좌표계 정의

```
행(row) 7  [ ][ ][ ][ ][ ]   ← 적 스폰 라인
행(row) 6  [ ][ ][ ][ ][ ]
행(row) 5  [ ][ ][ ][ ][ ]
행(row) 4  [ ][ ][ ][ ][ ]
행(row) 3  [ ][ ][ ][ ][ ]
행(row) 2  [ ][ ][ ][ ][ ]   ← 플레이어의 "정면/대각선" 판정 라인
행(row) 1  [ ][●][ ][ ][ ]   ← 플레이어 폰 고정 위치 (열: 1~5)
            1  2  3  4  5   (열, column)
```

- **행(row) 1~7**: 세로축. 1행은 플레이어 고정 라인, 7행은 적 스폰 라인.
- **열(column) 1~5**: 가로축. 플레이어와 적 모두 이 5개 레인 중 하나에 위치.
- 플레이어의 좌표는 `(row=1, col=C)`로 표기하며, 게임 내내 **row는 항상 1로 고정**된다. 캡처를 통해 **열(C)만 좌우로 바뀔 수 있다.**

> 설계 노트: "폰은 1행 고정"과 "폰은 앞으로 이동한다"는 요구사항은 컨베이어벨트(트레드밀) 구조로 해소한다. 플레이어가 실제로 앞으로 나아가는 것이 아니라, **보드(적들)가 플레이어 쪽으로 한 칸씩 흘러 내려오는 것**이 "전진"의 실체다. 대각선 포획 시에는 열(레인)만 이동한다.

## 3. 기물 규칙

### 3.1 플레이어 폰
- 위치: 항상 `(1, C)`. 시작 열은 중앙(C=3) 권장.
- 매 턴 판정 대상 3칸은 모두 **2행**에 있다.
  - **정면(Front)**: `(2, C)`
  - **좌측 대각선**: `(2, C-1)` (C>1일 때만 존재)
  - **우측 대각선**: `(2, C+1)` (C<5일 때만 존재)
- 가능한 행동:
  1. **전진(Forward)**: `(2, C)`가 비어 있을 때만 가능. 아무 것도 포획하지 않고 열 유지.
  2. **좌측 대각선 포획**: `(2, C-1)`에 적이 있을 때만 가능. 해당 적 제거 + 점수 획득 + 플레이어 열이 `C-1`로 변경.
  3. **우측 대각선 포획**: `(2, C+1)`에 적이 있을 때만 가능. 해당 적 제거 + 점수 획득 + 플레이어 열이 `C+1`로 변경.
- 실제 체스 규칙과 동일하게 **정면에 있는 적은 포획 대상이 아니다** (막힐 뿐, 잡을 수 없음). 오직 대각선의 적만 잡을 수 있다.

### 3.2 적 폰
- 매 턴(플레이어 입력 1회) 종료 시, 보드에 존재하는 모든 적 폰이 **자신의 열을 유지한 채 1행씩 하강**한다 (`row -= 1`).
- 적은 좌우로 이동하거나 방향을 바꾸지 않는다. 오직 직진 하강만 한다.
- 적은 **플레이어를 공격하는 별도 행동이 없다.** (아래 4장에서 설명하듯, 규칙상 적이 플레이어와 같은 칸에 놓이는 상황 자체가 발생하지 않도록 설계되어 있다.)
- 하강 결과 **1행에 있던 적은 다음 하강 시 보드에서 제거(소멸)**된다. 플레이어가 어떤 행동을 하든(전진이든 포획이든) 매 턴 이 소멸 처리는 동일하게 일어난다. (요청하신 "런닝머신" 컨셉 — 위에서 내려와 아래에서 사라짐)

## 4. 턴 진행 흐름

한 턴은 다음 순서로 처리된다.

1. **합법 행동 판정**
   현재 플레이어 열 `C` 기준으로 정면/좌측대각선/우측대각선 3칸을 확인해 가능한 행동 목록을 만든다.
2. **패배 체크**
   - 정면 `(2, C)`에 적이 있고
   - 좌측 대각선(존재한다면)도 비어 있고
   - 우측 대각선(존재한다면)도 비어 있으면
   → **합법 행동 없음 → 즉시 패배, 게임 종료.**
3. **플레이어 입력 대기**
   합법 행동 중 하나를 사용자가 선택. (선택지가 1개뿐이면 사실상 강제 이동)
4. **행동 처리**
   - 전진: 열 유지, 포획 없음.
   - 대각선 포획: 대상 적 제거, 점수 가산, 플레이어 열을 대상 열로 변경.
5. **월드 스크롤**
   보드 내 모든 적을 1행씩 하강시킨다. 이 과정에서 1행에 있던 적(하강 시 0행이 되는 적)은 제거된다.
6. **적 스폰 판정**
   아래 5장의 규칙과 안전장치를 통과하는 경우에만 7행에 새 적 폰을 생성한다.
7. 2번으로 돌아가 다음 턴 반복.

### 왜 적이 플레이어와 같은 칸에 놓이는 일이 없는가
정면(`2,C`)에 적이 있는 상태에서 플레이어가 전진을 선택하는 것은 애초에 규칙상 불가능하다(3.1 참조). 따라서 정면의 적이 그대로 살아남아 1행으로 내려오는 경우는 **반드시 플레이어가 그 턴에 다른 열(대각선)로 이동한 경우뿐**이며, 이때 플레이어의 새 열은 그 적의 열과 다르다. 즉 기하학적으로 두 기물이 같은 칸에서 만나는 경우는 발생하지 않으며, "적이 플레이어를 공격할 수 없다"는 규칙이 별도 예외 처리 없이 자연스럽게 성립한다.

## 5. 적 스폰 규칙 및 안전장치 (데드락 방지)

### 5.1 기본 스폰 규칙
- 매 턴, 확률적으로 0~N개의 새 적이 7행의 비어 있는 열들 중 무작위로 선택되어 생성된다.
- 한 열에는 동시에 하나의 적만 존재할 수 있다(같은 열이 이미 점유 중이면 그 열에는 새로 스폰하지 않음).
- 스폰 확률/개수는 난이도 곡선(6장)에 따라 점수/생존 턴 수가 늘수록 증가한다.

### 5.2 안전 불변식 (Safety Invariant)
요청하신 "플레이어가 어떤 선택을 해도 진행이 불가능한 상황 금지"를 만족하기 위해, 다음 불변식을 **항상** 유지해야 한다.

> 플레이어의 현재 열 `C`에 대해, `(2, C)`가 적으로 막혀 있다면, `C`에 존재하는 대각선(좌/우 중 실제 보드 범위 안에 있는 것) 중 **최소 하나는 반드시 적이 있어야 한다.**

- 가장자리 열(C=1 또는 C=5)은 대각선이 하나뿐이므로, 정면이 막힌 상태라면 **그 하나뿐인 대각선에 반드시 적이 있어야** 한다.

### 5.3 스폰 시점 검증 절차
적은 7행에서 생성되어 2행까지 도달하는 데 5턴이 걸리고, 그 사이 플레이어의 열은 본인의 선택(포획)에 따라 바뀔 수 있어 스폰 시점에 "미래의 플레이어 열"을 정확히 예측할 수는 없다. 따라서 다음과 같은 **매 턴 사전 시뮬레이션(1턴 룩어헤드)** 을 스폰 로직에 포함한다.

1. 신규 적을 스폰하기 전, "이번 스폰을 반영했을 때 다음 턴에 위반이 발생하는가"를 모든 도달 가능한 플레이어 열에 대해 검사한다.
2. 구체적으로, 스폰 직후 상태를 기준으로 각 열 `c (1~5)`에 대해 "만약 플레이어가 지금 열 c에 있다고 가정할 때" 5.2의 안전 불변식이 깨지는 조합이 되는지 확인한다.
3. 하나라도 위반이 발생하면 해당 스폰 시도를 취소하고 다른 열/다른 턴에 재시도한다.
4. 이 검증은 매 턴 반복되므로, 실제로 위반이 발생할 수 있는 시점(적이 2행에 도달하기 직전)에는 항상 최신 상태 기준으로 안전성이 보장된다.

### 5.4 구현 시 권장 사항
- 완전 탐색이 부담스러울 경우, 간단한 휴리스틱으로 대체 가능: "정면 열에 적을 배치할 때는, 인접 열 중 최소 하나에도 함께 적을 배치하거나 이미 적이 있는 상태를 우선 선택."
- 가장자리 열(1, 5)에 적을 스폰할 때는 안쪽 대각선(각각 2열, 4열)의 상태를 더 엄격히 확인.
- 유닛 테스트로 "임의의 시드에서 N턴 시뮬레이션했을 때 강제 패배가 한 번도 발생하지 않는다"를 검증할 것을 권장.

## 6. 점수 및 난이도

### 6.1 점수
- 대각선 포획 성공 시 **+10점** (기본값, 추후 밸런싱 가능).
- (선택) 생존 턴 수에 비례한 보너스 점수 부여 가능.
- (선택) 연속 포획(콤보) 시 가산점 부여 가능.

### 6.2 난이도 곡선
- 시간이 지날수록(또는 점수 임계값 도달 시) 적 스폰 확률/동시 스폰 개수를 점진적으로 증가.
- 단, 5.2의 안전 불변식은 난이도와 무관하게 항상 최우선으로 유지되어야 한다 (난이도는 "선택의 여지가 줄어드는 긴장감"으로 조절하되, "선택 자체가 사라지는" 상황은 금지).

---

## 7. 패배 조건 요약

- **패배**: 정면(2, C)에 적이 있고, 존재하는 대각선(들) 모두 비어 있어 아무 행동도 할 수 없을 때 즉시 게임 오버.
- 그 외에는 게임이 계속 진행되며, 별도의 시간 제한이나 체력 시스템은 없다.

## 8. UI/조작 (제안)

| 입력 | 행동 |
|---|---|
| 위쪽 방향키 / 탭 | 전진 (합법일 때만 활성화) |
| 왼쪽 대각선 버튼 | 좌측 포획 (합법일 때만 활성화) |
| 오른쪽 대각선 버튼 | 우측 포획 (합법일 때만 활성화) |

- 비합법 행동은 UI에서 비활성화(회색 처리)하여 플레이어가 항상 가능한 선택지만 보게 한다.
- 정면이 막힌 상태에서 대각선 중 하나만 가능할 경우, 해당 방향을 시각적으로 강조(예: 깜빡임)해 플레이어가 빠르게 인지하도록 한다.
