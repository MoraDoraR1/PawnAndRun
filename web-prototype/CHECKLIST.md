# Pawn&Run 리소스 & 이펙트 체크리스트

## 사운드 (SFX)
Web Audio API로 절차적 생성 — 외부 오디오 파일 없음.

- [x] 전진 (move)
- [x] 포획 (capture)
- [x] 무효 입력 (blocked)
- [x] 게임 오버 (gameOver)
- [x] 신기록 (newBest)
- [x] 시간 임박 틱 (tick, 남은 시간 ≤10초일 때 매초)
- [x] 시작/재시작 차임 (start)
- [x] 음소거 토글 (localStorage에 상태 저장)
- [ ] 배경음악(BGM) — 미적용, 필요 시 루프 오디오나 절차적 앰비언트 검토
- [ ] 연속 포획(콤보) 시 피치가 올라가는 등의 다이나믹 변주
- [ ] 모바일 진동(Vibration API) 피드백 — 포획/게임오버 시
